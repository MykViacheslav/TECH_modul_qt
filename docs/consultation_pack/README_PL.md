# Pakiet Do Konsultacji (GPT/Claude)

Ten folder zawiera gotowy pakiet do konsultacji wizualnej i UX naszej aplikacji TECH_modul.

## Co jest w pakiecie
- `KONTEKST_APP_PL.md` - skrocony kontekst biznesowy i przeplyw aplikacji.
- `CHECKLISTA_WYSYLKI.md` - jak wysylac materialy, zeby model ocenial tylko nasz ekran.
- `PROMPT_01_AUDYT_UX.txt` - audyt ogolny jednego ekranu.
- `PROMPT_02_COMPACT_MOBILE.txt` - uproszczenie widoku mobilnego (mniej tekstu).
- `PROMPT_03_POROWNANIE_IMAGEMETER.txt` - porownanie do stylu narzedzia pomiarowego.
- `PROMPT_04_MEGA_AUDYT_WIZUALNY.txt` - audyt calego pakietu (wiele screenow).
- `SCREENS_INDEX.md` - krotki indeks przykladowych screenow.
- `SCREENS_FULL_INDEX.md` - pelny indeks z miniaturami i linkami.
- `screens/` - przykladowe screeny (maly zestaw).
- `screens_full/` - maksymalny zestaw screenow (pelna konsultacja).

## Szybki start
1. Otworz `CHECKLISTA_WYSYLKI.md`.
2. Wybierz prompt `PROMPT_01/02/03` dla pojedynczego ekranu albo `PROMPT_04` dla calego pakietu.
3. Wklej prompt do ChatGPT lub Claude.
4. Dolacz odpowiednie screeny (lub caly katalog `screens_full`).

## Cel konsultacji
- poprawa wygladu i czytelnosci,
- lepsza wygoda pracy zwyklego uzytkownika,
- mniej zajetego miejsca przez tekst,
- bardziej narzedziowy, mobilny charakter interfejsu.
