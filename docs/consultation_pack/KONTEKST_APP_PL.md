# Kontekst Aplikacji (TECH_modul)

## Dla kogo
- wlasciciel firmy stolarskiej/projektowej,
- pomiarowiec,
- montazysta,
- nowa osoba wdrazana do pracy.

## Glowny przeplyw
`Start -> Nowe zamowienie -> Wycena -> Sciana (pomiary) -> Komplet/Modul -> Kalendarz/Czas pracy`

## Co jest wazne
- szybkie dzialanie na telefonie,
- malo tekstu na ekranie,
- duze i czytelne akcje,
- kontekstowe podpowiedzi avatara,
- onboarding nowej osoby przechodzacy miedzy zakladkami.

## Obecne cele UX
- uproszczenie interfejsu (compact mode),
- lepsze prowadzenie uzytkownika bez zaslaniania ekranu,
- lepsza ergonomia ekranu pomiarowego (jak narzedzie terenowe),
- latwe podpinanie pomiarow do projektu i wyceny.
